# 小逻 AI 短剧

使用作者原始工作流作为按需参考，把请求路由到最相关的一个或多个文件。所有参考文件均按 UTF-8 读取。

## 工作方法

1. 判断任务属于创作、分析、资产、分镜、场景、角色或拉片。
2. 完整读取对应参考文件；不要只读取 YAML 描述或局部标题。
3. 若任务跨阶段，先建立共享的角色、场景、道具和视觉不变量，再按制作顺序调用参考文件。
4. 保留用户已确认的剧本事实、人物身份、服装、空间关系、光线方向和道具状态。
5. 按所选参考文件的输出格式交付；用户明确要求解释、精简或改格式时再调整。
6. 参考文件提供方法与模板，不代表自动调用生图、生视频或剪辑服务。需要生成媒体时，继续调用当前环境中相应的生成 Skill 或工具。

## 跨阶段顺序

默认生产顺序：

`编剧/改编 → 剧本分析 → 资产 DNA → 角色与场景资产 → 分镜脚本 → 故事板/九宫格 → 视频生成 → 拉片复核`

若用户已有成熟剧本，可从剧本分析或资产 DNA 直接开始；若只有参考视频，则从拉片开始，再决定是否进入原创改编与重制。
