# 黏土白模故事板提示词模板

## 通用故事板总提示词

```text
根据以下剧本、人物设定与场景资料，生成一张专业电影预制作使用的 3D 黏土白模故事板。它是 white-model previs / monochrome clay render / untextured 3D blockout，不是彩色黏土动画，不是手工定格动画，不是最终电影剧照。

画幅：[16:9 / 9:16 / 2.39:1]。故事板页面布局：[2行3列共6格 / 3行3列共9格 / 用户指定]，每格保持相同画幅、清晰边框和编号，按从左到右、从上到下的顺序阅读。图内只保留编号、极短镜头标签和必要的运动箭头，不放长对白、气泡或字幕。

白模视觉：所有人物、头发、服装、道具、家具、建筑和地面统一使用象牙白至浅灰色的无贴图哑光黏土材质，低反射、高粗糙度，无肤色、无彩色衣服、无花纹、无品牌。人物采用自然真人比例的简化三维模型，面部保留可读的眼睑、鼻梁、嘴形和头部朝向；头发为稳定雕塑体块，服装只保留轮廓和大褶皱。环境保留门窗、道路、台阶、桌椅和关键道具等空间体块。

布光：中性大面积主光，柔和全局照明，清楚的环境光遮蔽、接触阴影和投影方向；白色模型与浅灰背景之间有稳定明度分离，高光不过曝，体积和前中后景清楚。中等景深，真实摄影机透视。

人物一致性：
角色A：[身高、体型、头发轮廓、服装外形、道具]
角色B：[身高、体型、头发轮廓、服装外形、道具]
所有格中人数、身份轮廓、左右位置、服装轮廓和道具保持连续，不新增角色。

场景：[地点、时间、空间结构、主要入口出口、固定物体]
剧情核心：[起点→转折→落点]

逐格内容：
1. [景别与角度]，[人物左右前后位置]，[唯一主要动作]，[摄影机运动]，[视觉焦点]。
2. ...
3. ...
4. ...
5. ...
6. ...

画面重点是镜头调度、空间比例、动作方向和剪辑连续性，不追求最终材质与装饰精度。相邻镜头具有明显信息差和构图差异，保持180度轴线、视线方向和出入画方向连续。

避免：彩色黏土、claymation、stop-motion、指纹与手捏痕迹、12fps跳帧、玩具大头比例、塑料光泽、陶瓷釉面、真实肤色、彩色眼睛、成片材质、复杂纹理、海报排版、漫画线稿、纯白过曝、轮廓融化、无接触阴影、重复机位、人物互换、服装变化、道具消失、异常肢体、额外手指、乱码、长文字。
```

## 单帧白模提示词

```text
[画幅]，电影预演用 3D 黏土白模关键帧，monochrome white clay render, clean white-model previs, untextured 3D blockout。[景别与机位]，[主体、动作、人物位置和朝向]，[场景中决定空间关系的几何体]。所有可见表面统一为象牙白至浅灰哑光材质，无贴图、无颜色、低反射、高粗糙度。中性大面积主光，柔和全局照明，环境光遮蔽与接触阴影清楚，高光不过曝，前中后景与人物轮廓可读。真实摄影机透视，中等景深，重点验证构图、比例、走位和镜头方向。不是彩色黏土动画，不是玩具，不是最终电影剧照。
```

## 参考图转换白模

```text
把参考图转换为电影预演用 3D 黏土白模画面。严格保留原图人物数量、身份轮廓、发型体块、身高体型、服装外形、道具外形、人物站位、身体动作、视线方向、相机位置、焦段透视、画幅和场景几何，不重新设计构图。仅移除所有颜色、贴图、品牌和真实材质，将人物、服装、道具和环境统一转换成象牙白至浅灰色的无贴图哑光黏土材质。加入柔和全局照明、环境光遮蔽、接触阴影和清楚体积，但保持原图光线方向。白模干净、专业、可用于镜头与空间检查；不是彩色黏土动画，不是陶瓷雕像，不是塑料玩具。
```

## 九宫格示例骨架

```text
1. 大远景｜场景和人物初始位置｜固定镜头
2. 中全景｜角色A沿既定路线接近｜侧向跟随
3. 过肩中景｜A发现角色B或关键道具｜轻微推入
4. 道具特写｜关键物被触碰或启动｜固定镜头
5. 双人中景｜关系发生变化｜横向弧移
6. 近景｜角色B作出反应｜缓慢推近
7. 顶视全景｜两人位置或行动路线改变｜升降
8. 动作峰值镜头｜关键动作完成｜跟随加轻推
9. 远景落点｜结果与环境关系｜缓慢拉远
```
