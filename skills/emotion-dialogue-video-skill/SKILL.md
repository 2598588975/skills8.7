# 台词×情绪×人物图 → 情绪表演视频（特写哭戏）

## 一、Planner（整体流程与里程碑节点）
按以下阶段顺序推进。每个阶段内容生成完毕后必须暂停展示结果，等待用户确认后进入下一阶段，不得自动跳入或合并阶段。

### 阶段 0：输入确认（必做）
向用户一次性确认以下输入：
1. 人物参考图 reference_image（URL/base64/文件）
2. 台词 line（任意文本，建议 ≤ 15 字）
3. 情绪词 emotion（任意词/短语，可多词组合）
4. 目标时长 duration_s（默认 15s）
5. 画幅 aspect_ratio（默认 9:16）
6. 台词口型时间窗 *line_time_window（默认 9s-12s；也可给相对百分比）
7. 场景约束 scene_constraints（默认：单人入镜、无文字、无logo、背景干净；可选是否禁道具）
8. 音频约束 audio_constraints（默认：无字幕、无讲解式口播；允许情绪化抽噎/哭腔）
确认完毕后进入阶段 1。

### 阶段 1：多模态分析（人物锚定 + 情绪解析）
- 对 reference_image 做人物要素抽取：脸型、五官特征、发型、妆容、服装风格、年龄感、气质关键词。
- 对 emotion 做情绪解析：提取情绪关键词并映射到表演强度与节拍结构（高唤醒/低唤醒、正向/负向、控制感强/弱）。
- 生成“身份锁定描述（identity lock text）”与“情绪标签（emotion tags）”。
展示分析结果给用户确认（是否需调整人物描述/镜头风格/约束），确认后进入阶段 2。

### 阶段 2：表演方法选择（AUTO 或 三段递进哭戏法）
- acting_method 默认 AUTO：根据 emotion 自动选择表演模板。
- 若 emotion 命中哭戏/痛哭/委屈/难过/失望/死心/害怕/恐惧/无助/内疚/认错等关键词，则 AUTO 默认使用：
  面部情绪三段递进法 THREE_STAGE_TEAR_ARC_V1（详见下文）。
展示所选 acting_method 与 0s-15s beats，等待用户确认后进入阶段 3。

### 阶段 3：提示词输出（Prompt + Negative + beats）
输出四项并展示给用户确认：
1. 正向提示词 Prompt（严格按公式组织）
2. 反向提示词 Negative（合并通用反向库 + 用户约束）
3. beats（0s-15s 分段表演节拍）
4. model_pack（Seedance2.0 建议：比例/时长/一致性注意/无文字注意）
用户确认后进入阶段 4。

### 阶段 4：生成视频（Seedance 2.0）
调用 media_generator（MultiModalToVideo / Seedance 2.0）：
- 输入：reference_image（作为身份一致性参考）+ Prompt + Negative
- 输出：情绪表演视频
生成后暂停展示视频，等待用户审核确认；如需重生成，支持：
- 调整 emotion / line_time_window / acting_method / beats 某段强度
- 增强“无文字/无logo/单人入镜”反向约束
- 降低 motion_strength 提升稳定性

## 二、Multimodal Analyze Tool（多模态分析工具）
当用户上传参考图时，必须输出结构化信息供后续提示词引用：
- 人物面部特征：脸型、眼型、鼻型、嘴型、痣/疤等识别点
- 发型与妆容：刘海、发色、妆感（自然/浓妆）、泪妆花掉可能性
- 服装与气质：日常/居家/职业等
- 画面风险项：画面是否含文字/水印/Logo/第二人物（用于反向约束加强）

情绪词解析输出：
- 关键词集合（如：害怕/无助/极度恐惧/崩溃等）
- 强度建议（low/medium/high）
- 推荐表演节拍结构（默认三段递进）

## 三、Acting Beat Designer（表演节拍设计）

### 1）核心公式（Prompt 组织顺序）
[人物主体] + [表情细节] + [身体动作/姿态] + [情绪/语气] + [口型/台词意图] + [镜头/构图] + [光线] + [场景] + [风格/质量]

### 2）默认哭戏模板：THREE_STAGE_TEAR_ARC_V1（面部情绪三段递进法）
内容保持不变（原始模板如下），用于 15s 极近特写哭戏。

面部情绪三段递进法：  
段落1：隐忍蓄泪(眉心收拢下沉、眼周充血泛红、泪珠悬于特写、死死克制不坠)  
->段落2：压抑破防(低头闭眼、眉心挤出川字纹、泪珠滑落面颊、鼻翼翕动、视线横瞥后收回)  
->段落3：失态痛哭(眉骨颤抖、泪水连帛滚落、唇角抽动、下颌松紧交替、鼻头泛红急促开合、柔弱克制小声痛哭)。  
全程贴合现代少女日常气质，每一组面部肌群运动都符合人体解剖学物理逻辑。

#### 【面部控制】
- 0s-4s：隐忍蓄泪。眉心肌群缓缓向内收越下沉，眼周肌肤逐渐充血泛红，泪腺慢慢蓄积泪水，泪珠悬于眼底边缘摇摇欲坠。口轮匝肌收紧，嘴唇据成一条坚绷的线，脸颊浅层肌肉微微绷紧。满腹委屈强行隐忍，死死克制泪水不坠落。  
- 4s-7s：压抑骤然破防。低头闭眼，眉心向下挤压出浅川字纹路。眨眼瞬间泪珠挣脱眼底，沿面颊肌理淌出两道湿润泪痕。急促呼吸带动鼻翼肌群规律翕动。  
- 7s-9s：抬眸后眼白浮现细碎红血丝，视线迅速横向瞥向画面右侧，转瞬收回目光落回镜头。鼻头随喘息淡淡泛红，慌乱藏于眼底。  
- 9s-12s：一声细碎哽咽响起，眉骨周边肌肉小幅无规则颤抖，泪珠接连滚落，唇角肌肉反复抽动，面颊与下颌肌群松紧交替。情绪彻底绷不住开始失态。  
- 12s-15s：眉心印出深川字纹路，眉峰随哭颤小幅抖动。双眼胀红，泪水充盈眼眶，眼睑频繁颤动，大颗泪珠连绵滑落，面部留下片状湿痕。鼻翼急促开合，鼻头泛红，面部肌群细碎抽搐，柔弱克制的小声痛哭，贴合现代少女日常气质。

#### 【运镜方式】
ARRI Alexa Mini LF+Cooke S7/i 100mm微距镜头，浅景深f1.8，极近特写，只取少女眉心至下巴区域，几缕垂落发丝和丝级领口微微入画边缘虚化。  
- 0s-7s：固定机位极近特写，聚焦少女眉心至鼻梁区域，浅景深将背景完全虚化为柔和光斑，仅靠面部肌群微表情变化驱动画面，呼吸节奏带动面部吸轻微起伏。  
- 7s-9s：固定机位，镜头随视线横瞥方向极缓慢微横移（幅度不超过画面5%），视线收回时镜头同步回正，模拟目光追随感。  
- 9s-15s：极缓慢推进(从极近特写推进至大特写)，画面逐渐只充满双眼至唇部区域，景深进一步收窄至f/2.0，泪珠滑落轨迹和面部湿痕细节逐渐画面逐潮放大，最终聚焦双眼胀红，泪珠连绵的终极情绪表达。

#### 【光影氛围】
整体色调冷青偏灰蓝，侧光为主光源，营造古装凄婉氛围。ARRI Alexa Mini LF 暖色偏琥珀底色，面部高光保留皮肤细腻质感。  
- 0s-4s：柔和侧光(色温4200K)，从画面左侧45度照射，眉心肌群收拢处有微妙阴影加深，眼周充血泛红在侧光下更显脆弱感，泪珠悬于眼底边缘。  
- 4s-7s：侧光强度微降，低头闭眼时面部阴影面积扩大，泪珠滑落面颊时泪痕表面有一道细长高光随重力方向流淌，鼻翼翕动处有动态光影变化。  
- 7s-9s：光线不变，抬眸瞬间眼白红血丝在侧光下清晰可见，初线横瞥时瞳孔高光点移动，收回目光后鼻头泛红在暖光下更明显。  
- 9s-15s：侧光渐转为冷调(色温降至3800K)，泪珠接连滚落时面部多道泪痕反射出细碎高光，双眼胀红在冷调光线下对比更强烈，面部片状湿痕，有湿润反光质感，最终画面笼罩在凄婉冷调柔光中，背景完全虚化为灰蓝色散景。

## 四、Media Generator（素材生成）

### 生成情绪视频（核心）
- 使用 MultiModalToVideo，模型：Seedance 2.0
- 输入：
  1) reference_image（人物身份一致性参考，最高优先级）
  2) Prompt（按公式组织，包含 beats 摘要与 line 的口型意图）
  3) Negative（强约束无文字/无logo/无第二人物/口型不崩）
- 输出：15s 情绪表演特写视频
- 生成后必须展示给用户审核确认；若需调整，回到 Planner 阶段 2/3 迭代。

## 五、Write the Prompt（提示词撰写）

### 1）Prompt 必须包含（按公式顺序）
- 人物主体：从 reference_image 分析出的身份锚点 + 用户补充
- 表情细节：acting_method 的 0-15s 分段要点（或完整 beats）
- 身体动作：微动作（肩颤/吞咽/擦泪等）与 emotion 匹配
- 情绪语气：由 emotion 解析结果写入
- 口型/台词意图：line 在 line_time_window 内出现；禁止画面文字
- 镜头/构图：极近特写、浅景深、推进/微横移规则
- 光线：4200K→3800K 冷灰蓝侧光（哭戏默认）
- 场景：干净背景、无可读文字、无logo
- 风格/质量：live-action、真实肤质、轻胶片颗粒、电影感

### 2）Negative 固定反向提示词（必须合并）
- 任何字幕/文字/标题/水印/logo/品牌标识/可读屏幕UI
- 卡通/动漫/CG感、过度磨皮塑料皮肤
- 面部崩坏五官错位、畸形手指、鬼影重影、严重模糊强噪点
- 口型对不上台词或嘴部形变异常
- 舞台化夸张表演、喜剧化表情
- 若 single_person_only=true：禁止第二人物入镜（含镜中倒影）

[表情细节] “彻底失望→心冷放弃→认命抽泣”的低能量崩塌（不争、不吵、不再挽回）：

0s-6s 心死发空：上眼睑沉重下垂，目光失焦发散、眼神没有攻击性也没有委屈挣扎；眼眶迅速泛红发亮，泪水直接溢出并缓慢滑落（不是爆发式哭），嘴角轻微下坠但几乎没有力气，脸部肌肉整体呈“松掉”的麻木感；
